# 盈多多 / Ying+ 产品需求文档（PRD）

> 项目定位：从 iOS 桌面小组件切入的个人投资仪表盘，优先解决「看一眼桌面就能掌握行情与持仓」的刚需。

## 产品一句话定义

一款面向个人投资者的 iOS 应用：以桌面小组件为载体，聚合股票/基金行情、自选股、持仓盈亏等关键信息，让用户以最低成本掌握资产动态。

## 产品方向

| 阶段 | 目标 | 状态 |
|---|---|---|
| 第一阶段 | 以天气、时钟小组件跑通 WidgetKit 完整链路，建立 App 基础架构 | 已完成 |
| 第二阶段 | 加入用户系统（邮箱验证码登录），建立全局登录态与后端服务 | 已完成 |
| 第三阶段（当前） | 接入 A 股/港股行情数据，提供自选股、K 线、大盘指数等核心行情功能 | 已完成 |
| 第四阶段 | 自选股云端持久化、持仓录入、持仓盈亏概览 | 进行中 |
| 第五阶段 | 行情提醒小组件、股价推送通知、多设备数据同步 | 规划中 |
| 第六阶段 | Apple 登录、App Store 上架、合规行情数据源 | 规划中 |

## 解决的用户核心痛点

- **行情信息分散**：自选股、持仓、大盘数据分散在券商 App、行情 App、基金平台之间。
- **错过关键波动**：没有桌面级提醒， important 涨跌需要主动打开 App 查看。
- **持仓盈亏不清晰**：买入成本、当日盈亏、累计盈亏缺乏一目了然的管理视图。
- **登录与数据同步麻烦**：更换设备或 App 重启后需要反复登录、重新配置自选股。

## 产品价值总结

把 iPhone 桌面从「应用入口」变成「个人投资仪表盘」：

- 无需打开 App，桌面小组件即可展示自选股、持仓盈亏、大盘指数。
- 打开 App 后，3 秒内看到关心的行情与资产概况。
- 数据云端同步，登录即用。

## 当前 MVP

### 用户与认证

- 邮箱验证码登录，新用户自动注册。
- 测试账号一键登录，方便开发与体验。
- JWT Token 持久化到 Keychain，App 重启后自动恢复登录态。

### 行情

- 行情页：大盘指数 + 自选股列表（需登录）。
- 股票详情：日 / 周 / 月 / 年 K 线图。
- 支持 A 股、港股代码搜索与行情查询。

### 基础能力

- 通用网络层：自动注入 Bearer Token、统一错误处理。
- 天气组件：验证网络请求链路。
- 时钟组件：验证 WidgetKit 本地渲染。
- 底部 Tab 导航框架：首页、行情、组件、设置。

## 后续核心功能

### 近期（1-2 个月）

- 自选股云端管理：增删改查、排序、分组。
- 持仓录入与盈亏概览：成本价、数量、当日/累计盈亏。
- 个人资产 Dashboard：总资产、收益曲线、持仓分布。

### 中期（3-6 个月）

- 行情提醒小组件：桌面展示自选股涨跌幅与关键价位。
- 股价推送通知：涨跌幅、价格阈值提醒。
- 多设备数据同步（iPhone / iPad）。
- Apple 登录（需 Apple Developer 账号）。

### 远期（6 个月以上）

- 基金行情与持仓支持。
- 智能盯盘：量价异动、财报/公告提醒。
- 社区/资讯模块（可选）。
- App Store 上架与合规审查。

## 技术约束

- WidgetKit 不支持 HTML/JS 渲染，组件 UI 必须用 SwiftUI 原生实现。
- 组件刷新由系统调度，开发者只能建议刷新时间，无法保证实时。
- 跨 App / Widget 数据共享需使用 App Groups。
- 金融数据需接入合规行情接口，生产环境避免使用未授权数据源。
- 真机运行与上架需配置 Apple Developer 团队。

## 关键术语

| 术语 | 说明 |
|---|---|
| 自选股 | 用户关注的股票列表，登录后云端同步。 |
| 持仓 | 用户实际持有的股票及其成本、数量。 |
| K 线 | 日/周/月/年级别的开盘价、最高价、最低价、收盘价、成交量数据。 |
| 行情提醒小组件 | 在桌面展示自选/持仓关键数据的 WidgetKit 组件。 |
