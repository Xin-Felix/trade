# Widgets Studio 产品需求文档（PRD）

## 产品一句话定义

一个 iOS 个人信息仪表盘应用。以桌面小组件为切入点，逐步演进为股票、基金等金融数据的个人资产管理工具。

## 产品方向

**第一阶段（当前）**：以天气、时钟等小组件跑通 WidgetKit 完整链路，建立 App 基础架构。

**第二阶段**：加入用户系统（Apple 登录 / 邮箱登录），接入后端服务。

**第三阶段**：接入股票、基金行情数据，提供自选股、资产概览等金融功能。

## 解决的用户核心痛点

- 投资信息分散在多个 App（券商、行情、基金平台）
- 无法一目了然查看持仓和自选
- 重要行情变化缺乏桌面级提醒
- 登录和个人数据同步困难

## 产品价值总结

把手机桌面从“应用入口”变成“个人信息仪表盘”，让用户以最低成本掌握天气、行情、资产等关键信息。

## 当前 MVP

- 用户系统：Apple 登录 + 邮箱登录 UI
- 通用网络层：支持 Token、统一错误处理
- 天气组件：验证网络请求链路
- 时钟组件：验证 WidgetKit 本地渲染
- 底部 Tab 导航框架

## 后续核心功能

- 股票 / 基金行情展示
- 自选股管理
- 持仓盈亏概览
- 行情提醒小组件
- 多端数据同步

## 技术约束

- WidgetKit 不支持 HTML/JS 渲染
- 组件刷新由系统控制
- 跨端需要 App Groups 共享数据
- 金融数据需接入合规行情接口
